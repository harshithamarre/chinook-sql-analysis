# 🎵 Chinook SQL Analysis

A data analysis project exploring the Chinook music store database using Python, SQLite, Pandas, and Matplotlib — all inside a Jupyter Notebook.
 

## 📌 Project Overview

The Chinook database represents a fictional digital music store. This project involves connecting to the SQLite database, exploring its schema, writing SQL queries to answer business questions, and visualizing the results using Python.

The analysis focuses on:

- Best-selling tracks
- Revenue generated by each country
- Top-performing sales employee

---

## 🎯 Objectives

- Connect Python to the Chinook SQLite database.
- Explore the database schema and understand table relationships.
- Write SQL queries to answer business questions.
- Load query results into Pandas DataFrames.
- Create data visualizations using Matplotlib.
- Demonstrate SQL and Python integration for data analysis.

## 📂 Database Schema

The Chinook database contains multiple related tables.

### Main Tables

| Table | Description |
|--------|-------------|
| Customer | Customer information |
| Invoice | Customer purchases |
| InvoiceLine | Purchased tracks in each invoice |
| Track | Music tracks |
| Album | Album details |
| Artist | Artist information |
| Employee | Sales support representatives |
| Genre | Music genres |

### Database Relationships

```text
Artist
   │
   ▼
Album
   │
   ▼
Track
   │
   ▼
InvoiceLine
   ▲
   │
Invoice
   ▲
   │
Customer
   ▲
   │
Employee
```

Relationship Summary:

- One Artist → Many Albums
- One Album → Many Tracks
- One Customer → Many Invoices
- One Invoice → Many Invoice Lines
- One Employee → Many Customers

---

## 📊 Analysis Performed

### 1. Top 10 Best-Selling Tracks

Calculated the total number of units sold for each track by joining the **Track** and **InvoiceLine** tables.

---

### 2. Revenue by Country

Calculated the total revenue generated from each country using the **Customer** and **Invoice** tables.

---

### 3. Top-Performing Sales Employee

Determined which employee generated the highest revenue through customer purchases by joining the **Employee**, **Customer**, and **Invoice** tables.


```bash

```


### 4. Launch Jupyter Notebook



Run all cells to reproduce the analysis.
